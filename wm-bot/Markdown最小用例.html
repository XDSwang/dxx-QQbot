Markdown 最小用例 · 一张图 + 一个内容字符串

左边是「QQ 里应该看到的样子」，右边是真正发出去的请求体。 本地预览把图片换成了同一张 PNG 的 data URI，只是为了离线能看图； 真实发送用的是图片 URL，请运行 python md_probe.py --send 实测。

① 客户端应该看到的一条消息
内容字符串测试：如果这段文字和上面的图片出现在同一条消息里，说明自定义 Markdown 转换成功。

图片 URL（真实发送时）：
https://example.com/wm-card.png

② 实际 POST 的请求体 
{
  "msg_type": 2,
  "markdown": {
    "content": "![img #618px #224px](https://example.com/wm-card.png)\n\n内容字符串测试：如果这段文字和上面的图片出现在同一条消息里，说明自定义 Markdown 转换成功。"
  }
}

markdown.content 原文：

![img #618px #224px](https://example.com/wm-card.png)

内容字符串测试：如果这段文字和上面的图片出现在同一条消息里，说明自定义 Markdown 转换成功。
怎么判断成功：手机 QQ 里这一条消息同时出现「图片」和「内容字符串」= 转换成功，可以放心用 WM_QQ_MARKDOWN = native；只出现文字或整条发不出去 = 平台不放行该图片 URL，换 --image media 用官方素材对照， 或设 WM_QQ_MARKDOWN = 0 走已验证的富媒体图文混排。 Markdown 文字本身没有颜色语法，红蓝灰只存在于卡片图里。
