# QQ 群接入与授权操作说明（单独文档）

这份文档只讲「群」这一件事：怎么把机器人加进普通 QQ 群、平台侧那个「添加群号 / 授权」是什么、
群里「设置权限」怎么点、以及加完以后本项目 `data/groups.txt` 该填什么。

整体接入、凭证、配置与查价用法见 `QQ官方机器人接入指南.md` 和 `wm-bot/python/使用说明.txt`。

> 适用：本项目 `wm-bot/python/qq_bot.py`，腾讯官方 QQ 机器人（q.qq.com / bot.qq.com），普通 QQ 群。
> 依据 2026 年现行的**新版管理端**。
> 配置位置：`wm-bot/python/config.txt` 是可上传的纯净模板；填好凭证的副本在 `wm-bot/python/data/config.txt`
> （整个 `data/` 已被项目根目录 `.gitignore` 排除）。本文提到的 `data/config.txt` 都指后者。
> 重要：网上老教程里的「沙箱配置 → 在 QQ 群配置 → 下拉选 QQ 群 ID」已经停用，照着找会找不到，别浪费时间。

---

## 0. 先分清两个「群号」（最容易踩的坑）

| | 平台侧群号 | 项目侧 group_openid |
|---|---|---|
| 长什么样 | 纯数字，例如 `123456789`（示例） | 字母数字串，例如 `EXAMPLE_OPENID_A1B2C3...`（示例） |
| 在哪用 | QQ 客户端加群、管理端「添加群号 / 授权群聊」 | `wm-bot/python/data/groups.txt` 白名单 |
| 管什么 | 机器人**能不能进这个群、能不能收到群消息** | 我们的程序**要不要回这个群** |
| 从哪来 | QQ 里直接看到的群号 / 管理端下拉选 | 群里 @ 一次，从 `data/bot_flow.log` 抄 |
| 能不能互换 | **不能**。数字群号填进 `groups.txt` 会永远静默 | 同左 |

一句话：**平台授权用数字群号，项目白名单用 group_openid，两件事都要做，缺一个都不回。**
`group_openid` 跟机器人 AppID 绑定，换电脑 / 换手机不变，不用重抓。

## 1. 网页管理端：只做这 4 件事

用**创建机器人时那个 QQ 号**登录 https://q.qq.com ，进入你的机器人管理页。

1. **「设置 AI 服务 / 服务接入」跳过**（选「稍后连接」）。
   我们是自己跑 Python 的原创机器人，不让平台代跑，这步不做也不影响收发消息。
2. **开发设置 → 事件订阅与回调方式 = WebSocket**。
   本项目是 WebSocket 长连接。注意：不要切到 Webhook，官方说明切换是**立即生效**的，
   切错会让正在跑的机器人收不到事件。
   若页面里还有「事件订阅 / 能力权限」勾选项：保留**群 @ 消息**和**单聊消息**两类即可
   （`data/config.txt` 的 `WM_QQ_INTENTS = 33554432` = `1<<25`，这一位实际覆盖
   群@、群全量消息、单聊、通知开关、进退群与好友事件）。
   **免 @ 和主动发言不在这里设置**：它们是手机 QQ 里【群资料页 → 机器人设置】
   按群单独开的两个开关（「机器人可获取的群聊消息范围 = 获取群内全部消息」、
   「机器人主动在群聊内发言」），详见《QQ官方机器人接入指南》第七节；
   不勾管理端的额外权限也照样能回复 @ 指令。
3. **开发设置 → 服务器 IP 白名单：留空，一个都别填**。
   官方规则是「未设置 = 允许所有来源 IP；设置后 = 只有白名单 IP 能调接口」。
   你是电脑 / 手机单机跑，家里宽带、手机流量的出口 IP 会变；填了以后一换网络就会报
   「接口访问源 IP 不在白名单」。这条对**移到手机**尤其关键。
4. **服务范围 / 使用范围**：
   - 个人主体：暂不支持「公开使用」，只能把机器人加进**你自己是群主或管理员**的群；
     进群数量上限 500 个，本项目完全够用。未认证时同样只允许加自己是群主/管理员的群。
   - 如果你当前界面里有「**添加群号 / 授权群聊 / 添加群**」这类入口：填的是**数字群号**，
     并且只能选你是群主 / 管理员的群。这一步只是给平台授权「这个群允许机器人进」，
     **不等于项目白名单**，做完还得做第 3 节。
   - 私聊测试（群聊用不到）：新版管理端「开发设置 → 内部体验号码 / 开发体验用户号码」，
     最多加 20 个 QQ 号；管理员本人可直接测试，无需额外添加。

> 关于「沙箱配置」：官方 FAQ 已明确「旧版管理端已不支持添加沙箱群 / 频道配置」，
> 新版管理端用管理员账号可直接测试、**无需沙箱环境**。所以老教程让你去
> 「沙箱配置 → 在 QQ 群配置 → 选 QQ 群 ID」的步骤，现在不用做，界面里也找不到。
> 群成员 ≤ 20 人、必须是群主等，也是旧版沙箱规则，新版不适用。

## 2. 手机 QQ：加群 + 「设置权限」（群主本人操作）

前提：**手机 QQ 升级到最新版**、用**创建机器人的那个 QQ 号**登录、你是该群**群主或管理员**。
官方对个人主体加群的要求就是这样，网页端不一定能加。

### 2.1 常规路径
1. 打开目标群 → 右上角进入**群设置** → **群机器人**。
2. 进机器人列表 / 商店页，找到你创建的机器人（有时在「其他 / 测试机器人」里），点**添加**。
3. 弹出授权确认时点**确认 / 授权确认添加**；若让你选群，选这个目标群。
4. 群里出现机器人成员，即加群成功。只有进了群，它才收得到该群的 @ 消息。

### 2.2 备用路径（列表里找不到机器人，或提示「暂不支持加入」）
用创建者 QQ 在管理端扫「QQ 群和消息列表机器人二维码」→ 打开机器人资料卡 →
「添加到群 / 添加到机器人」→ 分享到目标群 → 打开资料卡 → **添加到本群** → 授权确认。
官方对「机器人暂不支持加入」给的办法也是：升级最新版 iOS / Android 手机 QQ，改用手机端扫码添加。

### 2.3 添加时的「设置权限」（就是你说的麻烦那一步）
加群时点「**设置权限**」，官方给群主的三项能力：

| 能力 | 作用 | 本项目要不要开 |
|---|---|---|
| 接收全量消息 | 机器人能收到群里所有人的发言（不只是 @） | **不用**。我们只订阅 @ 消息事件 |
| 主动推送消息 | 机器人能主动在群里发言（定时推送等） | **不用**。只在有人 @ 时被动回一条 |
| 撤回成员消息 | 机器人被设为群管理员后可撤回成员消息 | **不用**，也别把机器人设成群管理员 |

**保持最小权限即可**：只要机器人是群成员、能被 @，本项目的 `WM` / `ZK` / `翻译` 指令就能回。
程序只订阅 @ 事件，就算开了「接收全量消息」也不会收到闲聊，纯粹没必要、还多给一份权限。
官方 FAQ 里「@ 不回复就去开接收全量消息」那条是针对需要收全量消息的机器人，我们不属于这类；
群里 @ 没反应时，先按第 5 节排障逐项查。

> 另外：机器人**不会主动聊天**。只有被 @ 且消息带 `WM` / `ZK` / `翻译` / `/报错` 等触发词才回一条，
> 其它消息一律静默，白名单外的群彻底静默。这是设计规则，不是权限没开。

## 3. 项目侧：把 group_openid 手工写进白名单//重点***

平台授权解决「机器人进群」，这一步解决「程序只回你指定的群」。

1. 临时放开一次，二选一（推荐第一种，不改文件）：
   - `python qq_bot.py --allow-all-groups`
   - 或把 `data/config.txt` 的 `WM_QQ_ALLOW_ALL_GROUPS` 改成 `1`
2. 在群里**从 @ 列表点选机器人**（手打昵称不触发），发 `WM Boltor Prime`（或 `翻译 Boltor` 查名称对照），等它回一条。
3. 打开 `data/bot_flow.log`，找 `群@消息 group_openid=...`，抄后面那串字母数字。
4. 用记事本打开脚本同目录的 `data/groups.txt`，单独一行写进去，`#` 后可写备注：

   ```text
   EXAMPLE_GROUP_OPENID_A1B2C3D4E5F6      # 我的交易群（换成你自己抓到的字符串）
   ```

5. **收尾必做**：关掉程序；若改过 `data/config.txt` 就改回 `0`；重新 `python qq_bot.py`。

> 白名单是**纯手工**的：程序不会自动发现群、不会自动打印提示、更不会自动写入 openid。
> 白名单外的群一律静默（连「我不在名单里」都不发）。改完要重启程序才生效。

## 4. 加完群后的验收清单

按顺序打勾，哪一步断了就回对应小节：

- [ ] 启动日志出现 `群白名单已加载 1 个：...`（说明 `groups.txt` 读到了）
- [ ] 群成员列表里有这个机器人
- [ ] 群里**从 @ 列表点选**机器人发 `WM Boltor Prime`，能收到**一条消息**：价格卡片图（订单列表、来源网址、卖家状态）+ 同条消息里可复制的中英文 `/w` 指令
- [ ] 发一句闲聊，机器人不回（静默规则正常）
- [ ] 在另一个没写进白名单的群 @ 它，不回（白名单隔离正常）
- [ ] 私聊机器人发 `WM Boltor Prime`，能回（私聊不受白名单限制）
- [ ] `data/bot_flow.log` 里没有 AppSecret（本来就不记录 secret；日志按天归档保留，重启不再清空）

## 5. 群相关排障表

| 现象 | 原因 / 处理 |
|---|---|
| 群里 @ 完全没反应，日志里也没有群事件 | ① 机器人没进群（第 2 节）；② 不是从 @ 列表点选（手打昵称不触发）；③ 该群没写进 `groups.txt`；④ 换网络后被 IP 白名单挡了（第 1 节第 3 条，清空白名单） |
| 提示「机器人暂不支持加入」 | 手机 QQ 不是最新版 / 不是用创建者账号 / 你不是该群群主或管理员；改用 2.2 的手机端扫码添加 |
| 群机器人列表里找不到自己的机器人 | 走 2.2 备用路径；确认登录的是创建机器人的 QQ 号、且账号是超级管理员 |
| 私聊能回、群里不回 | 多半是没从 @ 列表点选，或该群不在 `groups.txt`；先看 `bot_flow.log` 有没有 `群@消息` 那一行 |
| 换 WiFi / 改用手机流量后连不上 | 管理端填过「服务器 IP 白名单」→ 清空。单机 / 手机出口 IP 会变，留空才不会被挡 |
| 老教程里的「沙箱配置 / 在 QQ 群配置」找不到 | 正常，旧版已停用；新版管理员直接测、无需沙箱（第 1 节末尾） |
| 把数字群号填进 `groups.txt`，还是不回 | 填错了。平台授权用数字群号，项目白名单要 `group_openid`（第 0、3 节） |
| 回复报 `40034027 ... event_id ... 对应事件不能回复消息` | 被动回复字段用错；本项目已固定用 `msg_id = d.id`。这是代码层问题、不是群权限问题，确认跑的是当前代码 |
| 电脑和手机同时开着，群里时回时不回 | 同一个 AppID 只能有一个在线长连接，关掉另一台（移到手机时尤其注意） |
| 给机器人设了管理员 / 开了全量消息，仍然只回 @ | 正常：程序只订阅 @ 事件、只对触发词回复，不会主动聊天 |

## 6. 权限与安全小结

- 给机器人的权限保持**最小**：群成员即可，不必管理员；不必开全量消息。若要用「世界状态监控」功能，
  需在群资料页按群打开「机器人主动在群聊内发言」。10 秒只是**检查节拍**，真正发送受
  「内容不变不重发 + 300 秒周期间隔」约束；`警报`/`活动` 主推只在出现新条目时立即推
  （60 秒防抖），远低于官方 20 qpm / 每群每天 1000 条的频控，无需额外开权限开关。
  默认**不会自动往群里推消息**：`WS_AUTO_PRIORITY = 0`。推荐由用户在群里自己发
  `活动=开启` / `警报=开启` 来开启（发消息才设、按会话存到 `data/ws_switches.json`、重启自动恢复），
  发 `活动=关闭` 或 `停止监控` 即停；不同群各自独立，不会擅自给没设置的群发消息。
  白名单外的群发这些指令也一律静默。
- `wm-bot/python/data/config.txt` 含 AppSecret：整个 `data/` 已被项目根目录 `.gitignore` 排除，别手动加进版本控制，也别截图、发群、传网盘；会上传的 `wm-bot/python/config.txt` 是纯净模板（凭证留空）。
- `data/groups.txt` 只放 openid，不含密钥。
- 手机端若一直报 `[SSL: CERTIFICATE_VERIFY_FAILED] unable to get local issuer certificate`，
  与平台授权、群开关无关，是手机 Python 缺 CA 根证书：Termux 执行
  `pkg install ca-certificates` 后重跑；程序会自动探测 CA，实在找不到才临时关闭校验
  并打印警告（有中间人风险，建议尽快装证书，别用 `WM_SSL_NOVERIFY = 1` 长期跑）。
- 平台侧授权（数字群号）和项目侧白名单（group_openid）是两道**独立**的门，
  都只对你亲自指定的群开；程序不会自动发现新群、也不会自动加白名单。
- 官方入口：https://bot.qq.com/wiki/ （接入指南）、https://bot.qq.com/wiki/bot_FAQ （常见问题）。
  管理端与手机 QQ 的按钮名称会随版本调整，以当前界面为准；本文的关键规则（个人主体加群限制、
  IP 白名单留空、WebSocket、两个群资料页开关按群单独开）不变。
