英文：/w -Ar.Luna- Hi! I want to buy: Tigris for 800 platinum.

标题、统计、排序、订单列表、来源链接都在上面那张卡片图里， 所以文字区只剩两行可复制指令。只有主动发「文字 xxx」的纯文字回退才输出完整正文。

图片 URL 首选覆盖式固定公网地址 （网盘 / Git 里只有一张 card.png 反复覆盖）；没配置才用官方素材 qqbot-media://。本地预览把引用换成同一张 PNG 的 data URI，便于离线看图。

三条要点
  • 自定义 Markdown 已对单聊 / 群聊所有机器人开放，不需要模板审核；模板模式才需要后台审核拿 custom_template_id。
  • Markdown 文字只有加粗 / 斜体 / 链接 / 列表等，没有颜色语法。「游戏中红 / 在线蓝 / 离线灰」只存在于卡片图里；图不出来颜色就没了。
  • 图片拿不到引用（覆盖式上传失败、素材超限等）一律回退富媒体发图，绝不发「无图纯文字」；公网 https 图是否被 QQ 放行请用 python md_probe.py --send --group <openid> --image overwrite 真机实测，不行就设 WM_QQ_MARKDOWN = 0。
