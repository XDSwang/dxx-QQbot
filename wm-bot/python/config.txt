# 正确用法（三步）：
#   1. 把本文件复制一份到同目录的 data/ 文件夹下，文件名仍是 config.txt，

#      每一项下面都有中文注释。
#   3. 保存后运行 python qq_bot.py。程序【只读取 data/config.txt】，
#      不会读这份模板；只改模板却没有复制到 data/ 是不会生效的。

#   全部排除。不要手动把 data/ 加进版本控制，就不会泄露任何个人信息。
#   data/groups.txt 也要自己在 data/ 下新建（每行一个 group_openid）；
#   不建也行 —— 默认不监控任何群，私聊照常可用。
#
# 写法：每行一个「名称 = 值」
#   - 「#」后面的文字都是注释，随便写，不影响运行；
#   - 值里不要出现「#」；留空 = 用程序内置默认值；
#   - 等号左边的名称不要改；名称大小写不敏感；
#   - 路径一律相对【python 脚本所在目录】（不是相对本配置文件），
#     不要写盘符、不要写 ../ 上层路径；
#   - 编码 UTF-8（Windows 记事本存成带 BOM 的也能读）。

# ---------- 五、固定规则（不提供配置，写在这里只是说明） ----------
# 同域名访问间隔 3~5 秒：硬规则，真实源与离线演示都真等，不允许调小。
# 刷新失败：用户这次只尝试 1 次并立刻收到明确报错（不发旧数据），
#           1 / 3 / 7 分钟重试（累计最多 4 次）在后台继续，成功后自动更新缓存；
#           这样真实源挂掉时机器人不会假死、不会错过 QQ 被动回复的 5 分钟窗口。
# 缓存只按「用户实际查过的物品」建立，绝不预拉全站物品清单。
# 数据文件 cache.json / pace.json / worldstate.json / bot_flow.log / groups.txt 都在
# python 脚本同目录的 data/ 下，路径由脚本自己解析，整个文件夹拷到手机任意位置都能跑。

# ---------- 六、世界状态（星际战甲国际服：警报 / 平原 / 突击 / 裂缝 …） ----------
# 数据源：社区维护的 Warframe Status API（warframestat.us，开源、无需 key、已中文化）。
#   它的底层就是解析 DE 官方 worldState.php，数据同源；比直接抓官方原始 JSON 省事太多。
#   我们不抓官方 worldState.php：那是给游戏客户端用的原始 MongoDB 风格 JSON（几 MB、
#   内部码如 MT_MOBILE_DEFENSE），要移植解析器 + 自建本地化表，成本太高。
#
# 刷新节奏（核心：**不轮询、不反复查询，按数据自身到期时间更新一次**）：
#   每次抓取只发 1 个请求就把整个世界状态拿回来，同时记下「抓取时刻」，
#   并把各条数据的 expiry / activation / timeLeft（相对时长换算成 抓取时刻 + 剩余时长）
#   变成【绝对结束时刻】，去重升序排成队列写进 worldstate.json。
#   后台线程长睡到队首那一条的结束时刻，到点再发 1 次全量请求、重排队列，继续睡。
#   例：虚空商人没来时，队首就是他下次抵达时间（可能十几天），期间 0 次请求；
#       到他抵达/离场那一刻才更新一次。发「计划」可查看全部到期时刻。
#   - 节拍（任意两次全量请求之间的最小间隔）：10 -> 20 -> 50 -> 10 秒循环，
#     写死在代码里（WS_STEP_GAPS），【不提供配置】—— 防止被误调小后打爆接口。
#     真正决定「何时请求」的仍是队首那一条的结束时刻：队首在十几分钟后，节拍早过了，
#     也只等到期点，不会按节拍空转；队列为空 / 到期点异常时才靠节拍兜底。
#   - 失败退避：10 -> 30 -> 60 秒，之后保持 60 秒继续重试（成功后归零）；绝不无限快刷。
#   - 同域名 3~5 秒访问间隔是【硬规则，写死不提供配置】，与 WM 共用 pace.json 记录，
#     每次 HTTP 前都过一遍，保证任何两次访问【同一数据源域名】不短于 3~5 秒。
#   - WS_PUSH_SECONDS：监控【检查】节奏（秒），默认 10；只读缓存，不额外打接口。
#     注意它不是发送周期：主动消息权限开通后，只有「内容变了 + 过了 WS_ACTIVE_MIN_GAP」
#     才真的发一条，否则 10 秒一条会刷屏并撞官方频控。
#   - WS_WAKE_MAX：单次最长睡眠（秒），默认 3600，醒来重算计划防系统休眠漏点。
#   - WS_EXPIRY_GRACE：到期宽限（秒），默认 2，避开边界抖动。
#   - WS_HTTP_TIMEOUT：单次 HTTP 超时（秒），默认 15；连不上交给上面的退避，不会卡住机器人。
#
# 查询用「警报 / 平原 / 突击 / 仲裁 / 裂缝 / 钢铁裂缝 / 活动 / 赏金 …」任意词，
# 「计划」看到期时间表；「监控 <词>」「监控 全部」开自动推送，发「停止监控」停止。
# 全部指令发「帮助」（或「?」「菜单」）查看。

# ---- 回复形式：白底卡片图（默认）or 纯文字 ----
# 为什么要图：栏目多时纯文字一条消息上千字，容易触发风控、也不好看；
#             卡片图一屏给全、还能分组/对齐剩余时间。
# always（默认）：所有回复都优先发图（世界状态 / WM 查价 / 紫卡 / 帮助）
# auto          ：查询结果超过 WM_WS_CARD_MIN 字节才画图，短结果仍发文字
# off           ：只发文字（想复制文字的场景，图里的字选不中）
# 临时强压：发「图 裂缝」强制出图，发「文字 裂缝」强制只发文字，前缀优先于这里。
#           「文字」对 WM 也生效：文字 WM Boltor Prime 会回纯文本，方便复制 /w 指令。
# WM_WS_CARD = always
# WM_WS_CARD_MIN = 800
#   字体：默认自动找 微软雅黑 / 思源黑体 / Noto / 文泉驿；都找不到就自动退回纯文字。
#   要指定字体（例如 Linux 服务器）：
# WM_CARD_FONT = /usr/share/fonts/opentype/noto/NotoSansCJK-Regular.ttc
#   ★ 跨平台提醒：这个路径必须和【运行设备】一致！在 Windows 上配的 C:\...\wqy.ttf
#     同步到 Termux/手机端会失效（盘符/反斜杠在 Linux 上无效，自检会报 ⚠ 告警）。
#     最省事：把字体直接丢进 python/fonts/（随 python/ 同步，自动识别，无需本项）。
# 注意：渲染依赖 Pillow（pip install pillow）；没装 Pillow 时自动退回纯文字，不报错。
#       发图失败（无权限 / 图片过大）同样退回纯文字。
#
# 官方通道：WM 交易回复的「卡片图 + 中英文 /w 指令」默认合成【一条消息】
#   （富媒体 msg_type=7 同时带 content，仅图片支持图文混排；/w 仍是可复制纯文本）
# 1（默认）：一条消息，图上是价格列表、图下就是 /w 指令
# 0        ：退回两条（图一条 + 文本一条）；若发现客户端不显示混排文字，改成 0
# 混排被服务端拒绝时会自动回退成两条，无需手动干预。
