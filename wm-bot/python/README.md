# wm-bot — 已实现功能

> 纯 Python 标准库（只有卡片图可选 Pillow + 中文字体），桌面 / Termux / QPython 通用，
> 路径全部基于 `__file__` 解析，整个目录拷到任意位置都能跑，没有 `.bat` / `.sh` 启动脚本。
> 由公共库根目录的 `run.py` 统一拉起，服务入口 `qq_bot.py`；命令行可 `python wm.py "<指令>"`。
> **运行与部署流程见仓库根 `README.md`**，这里只列已经实现的功能。

## 1. Warframe Market 查价

- `WM <名称>` 查物品、`ZK <名称>` 查紫卡；中文名先经本地词库翻英文再查
  （`翻译 <名称>` 给中英对照 + 双 wiki 链接，`翻译 同步` 拉全量词库，之后纯本地零请求）。
- 名称 → slug 按需探测：只针对用户输入的这一个名称生成少量候选，**不拉全站清单**；
  命中的 slug 记进 `data/slug.json`，以后同一物品只发 1 个请求。
  全部候选 404 时明确提示改用完整名称，不启动后台重试。
- 订单按「游戏中 → 在线 → 离线」分组、同组内价格从低到高；
  久未登录的离线卖家沉到最后并标「N 天前在线」；紫卡「仅竞价」排在同组后面、
  已流拍的拍卖直接跳过。回复头部给出三种状态各多少条与代表价。
- 回复带 WM 完整来源网址，并给出英文、中文两条 `/w` 游戏内交易指令
  （QQ 里是与卡片图同属一条消息的可复制纯文本）。
- 按需缓存：只缓存用户实际查过的 `类型:名称`，落 `data/cache.json`，不预拉、不自启轮询；
  超过新鲜度就**先联网刷新再回复**，绝不发旧缓存；刷新失败立即明确报错，
  1/3/7 分钟后台重试最多 4 次，主线程不卡住、不错过 QQ 被动回复窗口。

## 2. 世界状态（星际战甲国际服）

- 数据源默认 wf.wiki（可切 `api.warframestat.us`）；突击另从 DE 官方端点补抓；
  仲裁由两张静态轮换表本地推算（7 天同步一次，平时查询零请求）；
  遗物 / 掉落来自 DE 官方中文 PublicExport；每周轮换来自社区中文站。
- 可查栏目：平原（五处昼夜，每处后面紧跟自己的赏金任务板）、裂缝 / 钢铁裂缝
  （常规星球与九重天分两块，各按古纪→前纪→中纪→后纪→安魂→全能排序）、
  警报、活动、入侵、突击、仲裁、赏金轮换、信条 / 终幕武器、午夜电波、
  虚空商人、瓦奇娅、Darvo 特惠、全局加成、新闻；`全部` 给精简总览、`计划` 看到期时间表。
- `遗物 <编号>` 给四档精炼的全部奖励与概率，`掉落 <物品>` 反查出自哪些遗物或制作材料。
- 缓存按**数据自身的到期时间**驱动：抓取时把各字段到期点排成队列，
  后台睡到队首那一刻才发一次全量请求，没有定时轮询；到期前查询零网络请求。

## 3. 监控与推送

- `监控 <词>` 一次性注册、`停止监控` 停止；`活动=开启` / `警报=关闭` 这类聊天开关
  按会话存盘、重启自动恢复，支持 `主推=开启`、`主推状态`、中英文 / 全角 / 多组写法。
- 警报 / 活动出现新条目、奖励或描述变化时**立即单独主推**（60 秒防抖，不受 300 秒周期限制）；
  其余栏目内容变化才推且至少间隔 300 秒，倒计时跳动不算变化；刚开监控只记基线、不补发历史。
- 主动消息发不出去（官方 `40034105`）时内容进暂存区，随本会话下一条消息附带；
  同一条内容被多人订阅会在一条消息里一起 @ 到人；发送串行排队，不连发刷频控。

## 4. QQ 对接与消息形式

- 两种后端共用同一套消息判定与路由：官方 QQ 机器人 API（默认，`group_openid`、
  WebSocket、access_token 自动刷新）与 OneBot v11（正向 / 反向 WS）。
- 接入群 @、群全量（免 @）、单聊、关系变更等事件；被动回复 5 分钟窗口与
  `msg_id` 按事件类型正确处理，发不出去自动回退主动通道。
  群白名单 `data/groups.txt`（默认不监控任何群），私聊不受限制。
- 回复默认渲染成白底卡片图（Pillow + 中文字体 + `render_card.py`；
  缺任一样自动退回纯文字，不会不回话）。官方端自定义 Markdown 是
  **一条消息＝完整卡片图 + 图下两条可复制 `/w`**，图里画好标题、统计、排序、
  订单与来源，文字区不重复正文。图片支持固定公网 URL 覆盖式上传、官方素材、
  自备图床；还有富媒体混排与纯文字多级回退。
- `文字 xxx` 强制纯文字、`图 xxx` 显式出图、`自检` 查图片能力；
  控制台 `[recv]` / `[reply]` / `[silent]` 三行可直接定位「发了指令没反应」。

## 5. 指令与工程约束

- `帮助` / `?` / `菜单` 调出全部指令一览；`/报错 <指令>` 强制重查；
  兼容旧别名 `/查询`、`/wm`（`wiki` 指令已改为「翻译」）。
- 同域名访问 3~5 秒节流（`data/pace.json` 落盘跨进程，写死不可调小）、
  1/3/7 分钟重试最多 4 次、全失败排 1 小时；确定性错误（全 404）不重试。
- 异常日志与流程日志分文件、互不覆盖；手机端自动探测 CA 根证书，
  实在找不到才临时关闭校验并打印醒目警告。

## 边界（没做的，不假装提供）

- 紫卡词条 / 属性筛选未做；平台固定 `pc`，未暴露 platform 参数。
- wiki 正文（获取方式、锻造材料、数值）被 Cloudflare 拦，机器人抓不到：
  「翻译」只回名称对照和两个链接，要看正文自己点开。
- DE 原始数据里没有的信使前哨 / 集团任务 / 建造进度，单条查询会如实提示。
